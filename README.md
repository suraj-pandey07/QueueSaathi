
# QueueSaathi – Smart Queue & Appointment Management App

QueueSaathi is a Flutter-based mobile application designed to simplify appointment booking and queue management.

## Project Overview

The application aims to help customers book appointments, receive digital tokens, and track their queue position in real time.

## Planned Features

- Customer registration and login
- Appointment booking
- Digital queue tokens
- Live queue tracking
- Admin dashboard
- Queue management
- Push notifications

## Technology Stack

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Messaging
- Provider
